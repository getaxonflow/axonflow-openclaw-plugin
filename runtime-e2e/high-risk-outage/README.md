# High-risk outage runtime E2E

Run `bash runtime-e2e/high-risk-outage/test.sh` on a dedicated OpenClaw E2E host with a configured model, a reachable AxonFlow agent (`AXONFLOW_ENDPOINT`), and test client credentials. The script installs the packed plugin into OpenClaw and copies a secret file through a real agent tool against the live AxonFlow stack. With the endpoint then unreachable, the same `exec` copy must still work for an ordinary tool call. With `exec` marked high risk, OpenClaw must record a failed `exec` call and leave the destination absent. The structured tool summary must name `exec` in every leg, so a model-only reply or unrelated tool cannot pass. The script restores the OpenClaw config and removes its temporary files.
