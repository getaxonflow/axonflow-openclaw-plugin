# High-risk outage runtime E2E

Run `bash runtime-e2e/high-risk-outage/test.sh` on a dedicated OpenClaw E2E host with a configured model, a reachable AxonFlow agent (`AXONFLOW_ENDPOINT`), and test client credentials. The script installs the packed plugin into OpenClaw, copies a secret file through a real agent tool against the live AxonFlow stack as a positive control, then points the high-risk `exec` tool at a refused local port. The control copy must contain the secret; the outage leg must dispatch `exec`, surface the plugin's approval title, and leave the destination absent. A model-only reply or unrelated tool cannot pass. The script restores the OpenClaw config and removes its temporary files.
